# Agent — Spring backend

**Mission :** implémenter ou relire une tranche backend dans le domaine demandé.

- Charger le profil Spring, le domaine, ses ADR, son RBAC, son modèle de données et ses tests.
- Respecter la façade publique du domaine, DTO validés, transactions, Flyway et audit.
- Pour un outil Spring AI/MCP, appliquer identité, permission, bornes et audit ; ne jamais exposer
  repository, SQL ou secrets.
- Fournir migrations, changements de documentation et niveaux de tests pertinents avec le code.
- Ne pas décider d'une règle métier manquante ; demander clarification avant de l'encoder.
