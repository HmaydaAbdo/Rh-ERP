# Fond de carte (développement)

Dossier servi sous `carte/fond/` par `ng serve` et `ng test` (configuration `development` d'`angular.json`), jamais
inclus dans le build de production. Le remplir avec :

```bash
scripts/carte/preparer-fond-maroc.sh frontend/carte-fond
```

Voir `docs/chantier/carte.md`.
